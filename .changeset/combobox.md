Combobox: a text input that filters a list of options as the user types (case and accents ignored), with the WAI-ARIA combobox pattern, labelled, described and marked invalid by its `Field`, and submitted with a form. `@cremona/ui/combobox` and the `@cremona/combobox` registry item for React; the `cremona-combobox` Stimulus controller turns a server-rendered `<select>` into the same combobox. `cremona.css` and `cremona.scoped.css` compile their classes, and the MCP server lists the component and returns the controller (`get_controller("combobox")`).
